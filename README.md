# deviance.dev

The public interface for **DEViance Intelligence** — an independent laboratory for agentic systems, public prototypes, and software that proves what it claims.

> The deviation is the method.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run lint
```

chosen production host.
